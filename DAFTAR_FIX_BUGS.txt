[BUG-01] SESSION TOKEN BISA DIPALSUKAN — FULL ADMIN TAKEOVER
Severity : KRITIS
Lokasi   : src/lib/auth.ts:60-62 dan src/lib/auth.ts:294-303
Deskripsi: verifySessionToken() selalu mencoba HMAC dengan fallback secret yang
           hardcode di dalam source code:
             "swdbot-motion-studio-secret-auth-session-key-2026"
           Secret ini juga ada di git history. Siapa pun bisa membuat cookie
           swdbot_session sendiri dengan payload:
             { key, email: "<email admin>", isAdmin: true, exp: Date.now()+7d }
           Semua route admin hanya memverifikasi verifySessionToken() +
           isAdminUser() -> akses penuh: /admin, ubah pricing, blokir user,
           top-up kuota, baca aktivitas semua user.
Bukti    : Sudah diverifikasi dengan PoC. Token buatan HMAC fallback diterima
           oleh algoritma verifikasi yang sama.
Fix      : 1) Hapus cabang fallback sepenuhnya (auth.ts:294-303)
           2) SESSION_SECRET wajib dari env, TANPA default value
           3) Ganti perbandingan string dengan crypto.timingSafeEqual
           4) Rotasi secret setelah deploy, paksa logout semua sesi lama
